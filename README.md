## Quick reference

- **Font:** Barlow (Google Fonts)
- **Brand blue:** `#205AA7` (`--sl-color-brand-primary`)
- **Price / promo red:** `#E00041` (`--sl-color-text-price`)
- **CTA red:** `#DC2332` (`--sl-color-action-cta`)
- **Breakpoints:** mobile 390, desktop 1440

## Status

Foundations and components are captured from the live site (20 Oct 2026). Interaction states (hover, pressed, focus, disabled, loading) and the H3/H4 text styles are Journey proposals pending client sign-off.
